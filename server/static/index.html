当前已具备预训练模型

无需从零训练即可识别。这里的“训练”是用本校的真实钢琴录音微调音高与起音识别。

音频 + 实际弹奏答案

只上传录音可以测试；要训练，还需同步 MIDI 或人工确认的音符标注。标准曲谱用作参考。

先验证，再决定是否启用

每轮生成独立候选模型，不自动覆盖当前模型。演示合成数据只用来熟悉流程。

01

准备真实录音，先挑出需要改善的场景

收集学生在实际 Pad、钢琴和教室中的录音，保留低音、和弦、连奏等有代表性的片段。先用短片段核验，避免把大量未标注长录音直接投入训练。

  • 支持 WAV、MP3、M4A、FLAC 等；单条 0.25～600 秒，单文件不超过 50MB。
  • 录音时避免旁人讲话和外放伴奏；保留原始录音供老师回听。
  • 文件名注明曲目、采集设备和片段，例如“曲目A_Pad01_片段01”。
02

标注实际弹奏，老师核验后再确认

在“录音与标注”选择录音，点击“识别这段录音”，试听并检查时间轴。识别结果可以作草稿，之后必须补上漏音、删除误报、纠正音高和起音时间。

学生把 C 弹成 D，训练答案就写 D。不能把谱面的 C 当成这段声音的答案；否则模型会被错误标注影响。

有同步 MIDI：导入与这次录音、这次演奏对应的 .mid 文件。整段时间统一偏移时，在“MIDI 偏移”中校正；例如 MIDI 在 0 秒起音，录音在 1 秒起音，填 +1。

只有真钢琴录音：让老师人工听辨并标注，或先用识别结果作草稿，再逐条修正。谱子 PDF、照片、MusicXML 和标准演奏 MIDI 不能直接替代本次弹奏的答案。

0.600, 60, 80
1.200, 64, 80
1.200, 67, 80

每行是“起音秒数, MIDI 音高, 力度”。上例是 0.6 秒的 C4，以及 1.2 秒同时弹出的 E4、G4。时间从录音开头算。当前微调不训练力度，没有可靠力度数据时可统一填 80。

核对整段录音，勾选“已核对整段音频”，点击“保存标注”。未核验的录音不会进入训练。

03

把训练集和验证集分开

为每条录音选择“数据用途”，填写“曲目 / 采集分组”，然后保存。训练集用于学习，验证集只用于检查效果。

素材分组示例数据用途
曲目 A 的多个片段 / 重录piece-A全部训练集
独立曲目 B 的录音piece-B全部验证集
还未核验的录音按原始素材分组暂不加入训练

同一曲目、同一原始录音切出的片段使用同一分组，不要拆到两边。系统能拦截同分组和完全重复音频，但不能代替人工识别改名、转码或裁切后的重复素材。

流程最低需要 1 条训练录音 + 1 条独立验证录音。判断改进时应使用更多独立曲目、设备和录音条件；不要把这个最低数量当作准确率验收标准。

要训练真实数据，先在录音库点击“将演示数据移出训练集”。演示与真实录音不能混合训练。

04

开始一轮小规模微调

进入“模型训练”，检查训练 / 验证录音数量。首次可以用 20～50 步，学习率保留 0.0001，随机种子保留 42，再点“开始微调与验证”。这些是试跑设置，不能保证效果提升。

  1. 系统先用基础模型识别独立验证录音，记录训练前结果。
  2. 后台更新最后一个起音识别阶段，显示实际损失曲线。
  3. 用相同验证录音评测候选模型，生成训练前后对比。

每轮都从基础预训练权重开始，不会自动在上轮候选权重上继续累加。步数不是“多点几次就更准”。可离开当前页面等待；停止服务或重启服务会中断未完成任务。

05

看独立验证结果，再决定要不要用

页面指标运营怎么理解
音符 F1综合误报与漏音的结果，独立验证集上越高越好。
精确率 / 误报音符看模型有没有听出实际没弹的音。
召回率 / 漏掉音符看实际弹出的音有没有被漏掉。
训练损失观察训练过程，下降不代表验证准确率提高。

训练验证按同一 MIDI 音高、起音相差不超过 50ms一对一匹配，多出的音计入误报。只有真实数据的验证 F1 提高、精确率未下降，才出现“启用此候选模型”。演示数据训练不开放启用。

没有提高：保留当前模型，先回查错误标注、时间偏移、重复素材和代表性，再准备下一轮。不要反复改同一小验证集直到分数变好；另留未参与调参的录音做最终复核。

即使出现启用按钮，也请先在录音页选择候选模型，听老师关心的错漏音片段，再使用“曲谱实测”测试真实演奏。

06

试用、启用，必要时切回基础模型

在“曲谱实测”选难度、左手 / 右手 / 双手、片段和模型。默认“听音辅助（跟弹等待）”：弹对当前音符或完整和弦才前进；错音、漏音、多音时等待，纠正后继续。时间流逝不会自动跳过。

跟弹判定基于所选声部的参考 MIDI与模型实际听到的音符。卡住不一定是学生弹错：回听保存的跟弹录音，在判定明细标记“实际弹对，应通过”或“实际有错，应等待”，核对误拦与误放行。当前流式配置采用 288ms 右侧上下文，完整反馈延迟以实际测量为准。另有“固定节拍对照”用于按 BPM、偏移复核录音。

可先进入“虚拟钢琴”快速验证：点击“完全正确弹”或“随机错误弹”，系统会自动启动、演奏所选片段并生成逐组结果；可调整错误比例，查看误拦、误放行和音符 F1，下载完整报告。自动演奏会弹完整段，实际跟弹游标仍由模型判断。也可启动模拟测试后，用琴键、电脑按键或和弦按钮发声。声音经过同一 WebSocket 模型链路，按键记录只用于独立核验；模拟音频不能代替真实教室录音，也不能用于正式模型启用。确认后回到“模型训练”启用合格候选。停止正在运行的麦克风会话后再切换；新会话使用新模型。发现问题可点击“使用基础模型”切回。

启用影响本机服务。原网站和其他设备需要接入同一服务后才会使用这版模型；Pad 麦克风访问需要有效 HTTPS / WSS。

常见情况

只有录音，能不能直接训练？

可以先识别测试。监督微调需要实际弹奏答案，不能只上传音频就把预测自动当真值。

不会看 MIDI 数字怎么办？

请老师或标注人员提供同步 MIDI / JSON。运营无需独自听辨。C4=60、D4=62、E4=64、F4=65、G4=67、A4=69、B4=71、C5=72；以 MIDI 数字为准。

MIDI 导入失败或时间不齐？

先确认是同一段演奏。偏移只修正统一时间差，不能修正速度变化。超出音频长度或出现负时间的标注会被拒绝，请先裁切到相同片段。

为什么训练后不能启用？

演示数据不开放启用。真实数据也需验证 F1 提高且精确率不下降。候选仍可单独选择作测试。

页面关掉，训练还在吗？

服务运行时任务在后台继续；服务停止或重启会中断未完成训练。刷新页面可查看已保存的任务记录。

能评测琴键音准偏了几音分吗？

当前识别 MIDI 音高和起音，不评测音分偏差，也不识别松键时刻或踏板。这里主要解决弹到哪个音的问题。
